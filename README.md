# תאונות דרכים בישראל

דשבורד אינטראקטיבי לניתוח תאונות דרכים בישראל (2003–2026), ברמת יישוב, רחוב, ואף תאונה בודדת — כולל מפה אמיתית (Leaflet + OpenStreetMap/CARTO).

**אתר חי:** https://idoporath.github.io/traffic-accidents-israel/

## מקורות נתונים
- [הלשכה המרכזית לסטטיסטיקה (למ"ס)](https://gis.cbs.gov.il) — שכבת "תאונות", 317,180 רשומות (2003–2026)
- [data.gov.il](https://data.gov.il) — אוכלוסייה לפי יישוב, ורשימת הרחובות הרשמית בישראל

## מה יש בדשבורד
- חיפוש חופשי לפי עיר או רחוב, עם ניתוח מלא (מגמה שנתית, חומרה, יום בשבוע, עונתיות, סוג תאונה, כלי רכב מעורבים)
- טאב כללי עם השוואה ארצית בין יישובים, נרמול לפי אוכלוסייה (תאונות ל-100,000 תושבים)
- פירוט כל תאונה בודדת (עד רמת רחוב) עם מיקום מדויק על מפה אמיתית
- כל הגרפים בקוד עצמאי, ללא תלות בספריות תרשימים חיצוניות

## הרצה מקומית
פשוט לפתוח את `index.html` בדפדפן — אין תלות בשרת (הכל בקובץ אחד, כולל הנתונים).
